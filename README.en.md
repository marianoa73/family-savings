# Family Savings

**A family "mini bank" that teaches children to save: they see their balance, achievements and goals; the adults approve and manage everything.**
A small PHP + MariaDB website styled after trading/broker platforms, so kids get used to how those look.

The goal is to teach children how to save, make their achievements (school grades, help at home, study) visible as rewards, and close the full
circuit: **earn → save → request a withdrawal → get what you wanted**. Children cannot have a bank account, so parents act as the administrators and
record, approve, reject or correct every entry. Nothing is deleted: mistakes are cancelled with a reversing entry.

It is informational only: no bank connection, no banking data. UI in Spanish. MIT license. See the Spanish [README](README.md) for details,
[`docs/security.md`](docs/security.md) for the security model and [`docs/install.md`](docs/install.md) to set it up.
